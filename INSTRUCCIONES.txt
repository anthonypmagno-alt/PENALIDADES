PORTAL COMPLETO: REVISION DE GUIAS + PENALIDADES

Este paquete integra Penalidades dentro del portal principal. El index.html conserva el inicio de sesión de Revisión de Guías. penalidades.html valida y reutiliza la sesión del portal; no tiene un formulario de login propio.

PUBLICAR EN GITHUB PAGES
1. Descomprime el ZIP.
2. En el repositorio que publicarás con GitHub Pages, carga el CONTENIDO de esta carpeta en la raíz (donde quedará index.html). No subas la carpeta contenedora como un nivel adicional.
3. Conserva juntos index.html, config.js, bridge.js, gestion-v2.html, pdv.html, pdv-v2.html, penalidades.html, process-worker.js, pdf-pdv.js y brecha-costos.js.
4. Espera a que GitHub Pages termine de publicar y abre la raíz del portal, por ejemplo https://TU-USUARIO.github.io/TU-REPOSITORIO/. Inicia sesión ahí y entra a la pestaña Penalidades. No abras un index.html independiente de Penalidades.

ACTUALIZACION DE PENALIDADES (09-10-2026)
- El filtro “Brecha (columna E)” permite seleccionar uno o varios valores de la columna E (Brecha) del Excel de penalidades.
- La descarga Excel del detalle incluye GUIA, PENALIDAD, PDV, PORCENTAJE DE EXONERACION, MONTO FINAL (S/) y MOTIVO DE DECISION.
- Estos cambios son de interfaz y no requieren ejecutar SQL en Supabase.
- Al actualizar manualmente, reemplaza index.html y penalidades.html. Si subes todo el ZIP, carga su contenido completo en la raíz del repositorio y conserva juntos todos los archivos indicados arriba.

La configuración apunta al proyecto Supabase akultekodxqmmfchxviq. El login usa las cuentas existentes de Supabase Auth. El archivo index.html corresponde al portal completo y debe conservarse para que se muestre ese login.

ACTUALIZACION SQL PARA EL TIMEOUT DEL RESUMEN
En Supabase, dentro del mismo proyecto, ejecuta una vez SUPABASE_SQL/supabase_penalidades_resumen_rapido.sql. Actualiza únicamente la función que entrega el resumen inicial. No borra tablas, liquidaciones, guías ni decisiones. La pantalla carga primero el resumen por periodo/PDV; las guías se solicitan por páginas cuando seleccionas una liquidación.

OTROS SQL (SOLO SI APLICA)
- supabase_penalidades_tasa_firma.sql: ejecutar solo si faltan las columnas Estado/Tasa de firma o si se requiere esa corrección. Es incremental y no reinicia datos.
- supabase_penalidades_autorizacion_perfiles.sql: ejecutar solo si una cuenta válida de administrador/encargado muestra “Cuenta no autorizada” DESPUES de iniciar sesión. No corrige contraseñas.
- supabase_costos_brecha_compartidos.sql: necesario únicamente si aún no se instaló la configuración compartida de costos de brecha.

No ejecutes una instalación desde cero ni scripts de reinicio para esta actualización.

CAMBIO DE CRUCE
En exportación de guías se busca primero coincidencia de guía y PDV; si el PDV no coincide, se usa la coincidencia por guía y la actualización más reciente.
